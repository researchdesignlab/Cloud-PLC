This branch includes documentation and programming manuals related to Cloud PLC 4.0, as well as Arduino libraries.

To run the program, you need to download the Cloud_PLC library along with other required libraries such as Adafruit_MCP4728, CloudPLCRTC, and PubClient, which are available in the Cloud PLC GitHub branch "cloudPLC4.0". After downloading, copy these files and paste them into your Arduino libraries directory.

Make sure that your ESP32 board version is between 1.0.4 and 2.0.1. This process is mandatory to run the program smoothly. Alternatively, you can install these libraries directly from the Arduino IDE's library manager.
